# Stage 5 — Pilot & Validation

## Objective

Test whether the MVP creates real value in real clinic workflows.

## Pilot strategy

Start small.

Prefer clinics that:
- treat foreign patients
- perform implants/prosthetics
- receive external documents
- experience manual data entry
- are willing to experiment

## What to measure

### Usage
- Patients created
- Connections created
- Documents uploaded
- Treatments recorded
- AI processing jobs
- Passport views
- Sharing events

### Efficiency
- Time to create a record
- Time to process a document
- AI correction time
- Manual entry avoided

### Quality
- Extraction accuracy
- Correction rate
- Missing information
- Failed processing

### Retention
- Weekly active clinics
- Returning staff
- Repeat document uploads
- Repeat passport use

## Interview questions

- What did this replace?
- What took the most time before?
- What still feels manual?
- Which information is hardest to obtain?
- What do you distrust?
- Would you pay?
- What would stop you using it?
- What feature would you remove?

## Success principle

Do not optimize for compliments.

Optimize for repeated behavior.

The strongest signal is:

> Clinics keep using the product because it saves them meaningful work.

## Exit criteria

We understand:
- strongest workflow
- weakest workflow
- AI usefulness
- adoption friction
- patient behavior
- willingness to pay
- next highest-value improvement
